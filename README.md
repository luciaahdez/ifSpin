# 7B.-Proceso-de-desarrollo-de-software

## Descripción
if{Spin} es una aplicación de ruleta de decisiones que permite al usuario ingresar una lista de nombres o elementos para realizar una selección aleatoria.
Cada vez que la ruleta realiza un giro, se selecciona un elemento disponible para posteriormente eliminarse de la lista (para evitar que la selección se repita) y se registra en un listado de resultados.

## Objetivo
Desarrollar una aplicación que facilite una selección aleatoria de elementos mediante una ruleta virtual, permitiendo que el usuario tenga un registro de selección, control sobre los resultados y consulta final de los resultados obtenidos.

##Funcionamiento
  1. El usuario elige la cantidad de elementos que desea ingresar
  2. El usuario registra uno a uno los elementos elegibles en la ruleta
  3. La ruleta selecciona uno de los elementos disponibles de forma aleatoria
  4. Se muestra el elemento seleccionado
  5. Dicho elemento se registra en una lista de resultados
  6. El usuario decide si realiza otro giro o detener el proceso
  7. Al finalizar, se muestra el listado de resultados obtenidos en el orden en que fueron seleccionados.


##Requerimientos
- Permitir que el usuario ingrese elementos a participar en la ruleta
- Realizar una selección aleatoria entre los elementos disponibles
- Separar el elemento elegido de los disponibles
- Registrar los elementos resultados
- Permitir que el usuario detenga la iteración
- Mostrar los resultados al finalizar

##Metodología del desarrollo
Metodología Kanban que permite visualizar y dar seguimiento al status de las actividades mediante un tablero compartido
